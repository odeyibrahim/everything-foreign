✅ After Import Checklist

Step 1: Import WXR → Tools → Import → WordPress → Upload shopyeno-complete-final.wxr
Step 2: Import Products CSV → WooCommerce → Products → Import → Upload yenolabel-products-complete.csv
Step 3: Add PHP Snippet → Code Snippets → Add New → Paste yeno-cart-endpoints.php → Activate
Step 4: Upload Images → Media Library → Upload logo to /wp-content/uploads/logo-yeno.png
Step 5: Upload Azure Teaser → Upload to /wp-content/uploads/azure-teaser.jpg
Step 6: Configure Shipping → WooCommerce → Settings → Shipping → Add zones & rates
Step 7: Set Up Payments → Paystack/Flutterwave → Enter API keys
Step 8: Create Menus → Appearance → Menus → Primary Menu (About, Shop, Collections, Contact)
Step 9: Set Homepage → Settings → Reading → Static page → Select Home
Step 10: Install WOOCS (optional) → For currency switcher shortcode [woocs sd=1]
